# UI Patterns

## Navigation

**Primary Navigation**: Side navigation with icons and labels for main modules (POS, Inventory, Reports, Settings)

**Secondary Navigation**: Contextual tabs within each module

**Breadcrumbs**: Show hierarchy in deep sections like Settings

## Forms

**Inline Validation**: Show errors immediately as users type

**Required Fields**: Marked with asterisk (*), explained in form header

**Action Buttons**: Primary action on right, cancel/back on left

**Auto-save**: Draft states saved automatically in offline mode

## Data Display

**Tables**: Sortable columns, filterable, with pagination for large datasets

**Status Indicators**: Color-coded badges (success, warning, danger) with icons

**Empty States**: Helpful illustrations and clear next actions

**Loading States**: Skeleton screens, not spinners, for better perceived performance

## Feedback

**Toasts**: For non-critical confirmations (top-right, auto-dismiss)

**Modals**: For critical confirmations or multi-step actions

**Inline Messages**: For contextual warnings or information

**Offline Indicator**: Persistent banner when offline, dismissible when acknowledged

## Touch-Friendly

**Minimum Target Size**: 44×44px for all interactive elements

**Spacing**: Adequate space between touch targets (minimum 8px)

**Gestures**: Swipe actions for quick operations in lists
